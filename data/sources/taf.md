<!-- excerpt:taf-purpose tags:timetable,taf -->
The TAF is a way to get help with certain class timetable issues. Please use it only if you’re unable to resolve the problem by choosing another available class time.
Use the class timetable guide to resolve the issue yourself first. Submit one TAF per subject. Average turnaround is 10 business days. The TAF is only open during the review period.
<!-- excerpt:taf-supported tags:timetable,taf,no_classes,core_clash -->
Supported TAF issues if you cannot resolve them yourself: no classes available for your subject (keep swap requests open); a mandatory class is clashing where clashing subjects are core on your study plan; clash with employment (case-by-case, not guaranteed); conflict with religious observances.
<!-- excerpt:taf-not-supported tags:timetable,taf,self_service -->
Issues not supported by the TAF: if the class time you prefer is full but other class times are available, do not submit a TAF. If you have clashing classes and there is space in other class times, do not submit a TAF; switch to an available class. A TAF without a supported issue will be declined.
<!-- excerpt:taf-docs-in-scope tags:timetable,taf -->
No classes available: no supporting documents; you must give preferred class time(s). Mandatory core clash: no supporting documents; give preferred class time(s) if switching into a full class. Employment clash: employer letter with letterhead, contact details, days and times of work.
<!-- excerpt:taf-restricted-categories tags:restricted,taf -->
TAF categories that this study treats as restricted (stop autonomous action): Academic Adjustment Plan or health-related reason; personal circumstances. Those requests must be routed for authorised human review and are not prepared as timetable tickets by the agent.
