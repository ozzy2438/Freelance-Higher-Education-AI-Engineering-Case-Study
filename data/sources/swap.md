<!-- excerpt:swap-clash-definition tags:timetable,self_service -->
A clash or problem status may mean classes overlap. Back-to-back classes are not a clash. Classes have a five-minute grace period at the start and end for travel time. Example: a class listed as 9–10am runs from 9.05am and ends at 9.55am.
<!-- excerpt:swap-available tags:timetable,self_service,swap -->
If other class times are available that do not clash, switch to one of them. Join an available class (no heart icon) and save. You must first select an available class before the heart icon appears for preferred full classes.
<!-- excerpt:swap-waitlist tags:timetable,self_service,full_class -->
To join a full class, request a swap via the heart icon (waitlist). Stay in your current class while pending. Swap requests are not guaranteed. Waitlists close at the end of the review and adjust period.
<!-- excerpt:swap-all-full-taf tags:timetable,taf,no_classes -->
If you cannot allocate to any class a subject offers because all options are full, check for messages about added classes, use the swap/waitlist even with no allocation, and if no places open submit a Timetabling Assistance Form in the no available classes category.
<!-- excerpt:swap-core-clash-taf tags:timetable,taf,core_clash -->
If mandatory core subjects on your study plan are clashing, fill out a TAF and select the Mandatory classes in core subjects clashing category.
